# Blog Posts

This directory will contain Markdown/MDX blog posts.

## Example Structure

When adding a blog post, create a file named `YYYY-MM-DD-slug.md`:

```markdown
---
title: "Why We Are Building Relief"
description: "The story behind Relief and why accessibility matters"
category: "behind-the-build"
author: "Relief Team"
publishedAt: "2024-06-23"
featured: true
---

# Why We Are Building Relief

Your blog content here...
```
